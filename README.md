# Introduction

Welcome to the Angular project starter kit!

# Project Setup

1. Install Eslint extension in VScode to integrate with .eslintrc.json file <br>
   _if this is your first time installing, ensure you have restarted VScode after this step_

2. Ensure your node version is at least **v20.2.0** to avoid issues when installing dependencies.

3. Copy the project to your new project repo.

4. Run the follwing command:<br>
   `npm install` <br>

5. Inside .husky/pre-commit replace `. "$(dirname "$0")/h"` with `npx lint-staged`

6. Change the project
